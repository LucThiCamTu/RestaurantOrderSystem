
# Restaurant Order System

## 1. Giới thiệu

Restaurant Order System là hệ thống đặt món và xử lý tại bếp.

Dự án hỗ trợ khách hàng đặt món trực tuyến, quản lý đơn hàng và theo dõi quá trình xử lý món ăn tại bếp.

## 2. Mục tiêu

- Xây dựng hệ thống đặt món trực tuyến.
- Quản lý thông tin món ăn.
- Tiếp nhận và xử lý đơn hàng.
- Theo dõi trạng thái đơn hàng.
- Tích hợp RabbitMQ để xử lý hàng đợi.
- Gửi thông báo trạng thái đơn hàng theo thời gian thực.

## 3. Công nghệ sử dụng

- Node.js
- Express.js
- HTML
- CSS
- JavaScript
- PostgreSQL
- RabbitMQ
- Socket.IO
- Docker
- GitHub

## 4. Cấu trúc dự án

- client: Giao diện người dùng.
- order-api: Backend API.
- database: Cơ sở dữ liệu.
- kitchen-worker: Dịch vụ xử lý tại bếp.
- notification-service: Dịch vụ thông báo.
